# Security Policy

Gridman stores API workspaces and collections as local files. Please treat reports involving workspace data, credentials, Git remotes, local file access, and request execution as security-sensitive.

## Reporting A Vulnerability

Please report security issues privately by opening a GitHub security advisory or contacting the maintainers through the project repository:

https://github.com/shahramgit/gridman/security/advisories

Do not report security vulnerabilities through public GitHub issues.

Include as much detail as possible:

- affected version, branch, or commit
- operating system
- steps to reproduce
- affected files or features
- expected and actual behavior
- proof of concept, if available
- potential impact

## Supported Versions

Until Gridman reaches a stable public release, security fixes target the current `main` branch.
